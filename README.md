# Google Docs Word Counter

Chrome extension that automatically turns on Google Docs' built-in "Display word count while typing" option.

[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/google-docs-word-counter/pkmpgkafldocbllmpjafigafihimehnh?hl=en)

## Run from source

1. Open `chrome://extensions` and turn on Developer mode.
2. Click **Load unpacked** and choose this folder.
